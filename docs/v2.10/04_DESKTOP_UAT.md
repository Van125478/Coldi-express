# Nghiệm thu desktop

Bảng này ghi kết quả đã được cung cấp cho đợt v2.10. Đợt viết tài liệu này không chạy lại các ca. PASS visual là bằng chứng hiển thị hoặc nghiệm thu bố cục, không phải PASS chức năng đầy đủ.

| Việc | Kết quả | Ghi chú |
| --- | --- | --- |
| Shipper tạo đơn QA-001 | PASS cơ bản | Desktop |
| Carrier tìm và Claim chuyến | PASS cơ bản | Desktop |
| Carrier tạo xe và tài xế | PASS cơ bản | Desktop |
| Carrier phân công chuyến | PASS cơ bản | Desktop |
| Driver nhận chuyến | PASS cơ bản | Desktop |
| Shipper xem phân công | PASS cơ bản | Desktop |
| Carrier ẩn đơn đã Claim khỏi sàn tìm chuyến | PASS cơ bản | Desktop |
| Mapbox tải bản đồ và marker sau khi có token | PASS cơ bản | Chỉ xác nhận bản đồ và marker hiện. Không thay cho E2E GPS của QA-001 |
| Chat hai chiều | PASS visual | Đã có bằng chứng hiển thị. Không kết luận chat lưu dữ liệu đã nghiệm thu đầy đủ |
| Bố cục Carrier Home, phân công chuyến, Driver Home, cấu trúc Chatbox | PASS visual | Nghiệm thu bố cục từ trước. Không phải PASS toàn bộ chức năng |
| Full E2E Pickup → GPS → Delivery của QA-001 | NOT RUN | Chưa nghiệm thu |
| Mobile và responsive | DEFERRED | Theo quyết định người dùng. Không làm trong đợt này |

Không có ca FAIL được ghi trong danh sách nguồn của đợt này.
